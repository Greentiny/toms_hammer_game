# 도마뱀 톰 항아리 게임 — 개발 기획서

Getting Over It 스타일의 웹 2D 물리 등반 게임.  
주인공 **도마뱀 톰**이 항아리 안에서 긴 망치를 휘둘러 세로로 긴 맵을 올라간다.

---

## 1. 프로젝트 개요

| 항목 | 내용 |
|------|------|
| 플랫폼 | PC 웹 브라우저 우선 |
| 장르 | 2D 물리 등반 (망치 반동) |
| 맵 | 세로로 매우 긴 단일 월드 |
| 그래픽 | Canvas 2D + 3D 스타일 PNG (2.5D 느낌) |
| 단계 | 지상 → 하늘 → 우주 |
| 엔딩 | 3단계 깃발 후 반전 피날레 |

### 핵심 특징

- 마우스만으로 망치 조작
- Matter.js 기반 중력·충돌·반동
- 추락 가능
- 단계별 깃발
- 마지막 반전 엔딩 (소행성 → 영혼 → 예수 → THE END)

---

## 2. 기술 스택

| 기술 | 역할 |
|------|------|
| HTML | 화면·기본 UI |
| CSS | 시작 화면, 버튼, 게임 UI |
| JavaScript | 게임 로직 |
| HTML5 Canvas | 캐릭터·배경·오브젝트 렌더링 |
| Matter.js | 중력, 충돌, 회전, 힘 |

Three.js 등 3D 엔진은 **사용하지 않는다**.  
실제 물리·렌더는 2D이며, PNG만 3D 렌더 스타일로 제작한다.

---

## 3. 화면·월드 구조

```
화면 (가로형 PC)
┌────────────────────────────────┐
│           (카메라 뷰)            │
│              🦎🔨               │
└────────────────────────────────┘

월드 (세로로 긴 맵)
            GAME END / 🚩
        ─────────────────
              우주 (3단계)
        ─────────────────
               🚩
              하늘 (2단계)
        ─────────────────
               🚩
              지상 (1단계)
        ─────────────────
             START
```

- Canvas는 브라우저 크기에 맞춤
- 배경은 가로폭에 맞추고 **원본 비율 유지** (찌그러짐 없음)
- 좌표계: **Y-down** (Matter.js / Canvas와 동일)
  - `(0, 0)` = 맵 상단 (우주)
  - Y↑ = 아래로 (지상 방향)

```

  assets/

    player/
      tom-body.png

      ufo.png, spaceship.png, alien.png, asteroid.png ...
```

이미지가 없으면 **임의의 PNG를 만들지 말고** 도형 placeholder를 쓴다.  
나중에 파일만 교체하면 되도록 경로를 코드에 고정한다.

## 5. 게임 상태

```
MENU → PLAYING → STAGE_CLEAR → PLAYING → ... → ENDING → GAME_END
```

| 상태 | 설명 |
|------|------|
| `MENU` | 시작 화면 |
| `PLAYING` | 일반 플레이 |
| `STAGE_CLEAR` | 깃발 도착 연출 (플레이 중단 최소화) |
| `ENDING` | 피날레 연출 (조작 비활성) |
| `GAME_END` | THE END 화면 |

엔딩 중에는 일반 물리가 연출을 방해하지 않도록 분리한다.

## 6. 개발 단계 (로드맵)

처음부터 전부 만들지 말고 **아래 순서대로** 진행한다.  
**가장 중요한 원칙: 그래픽보다 망치 물리를 먼저 완성한다.**

### ✅ 0단계 — 기반

- [x] 프로젝트 기본 구조 (`index.html`, `style.css`, `game.js`, `assets/`)
- [x] 세로형 게임 월드
- [x] 긴 배경 이미지 (노을 → 하늘 → 우주)
- [x] 배경 가로 맞춤 + 비율 유지
- [x] 카메라 스크롤 / 월드 ↔ 스크린 좌표 변환
- [x] 배경 살짝 어둡게 + 블러

---

### ✅ 3단계 — PNG 플레이어 적용 (현재까지 반영)

에셋이 먼저 도착해 플레이어 비주얼을 물리보다 앞서 적용함.

- [x] 관절 파츠 적용: box, body, head, tail, arms, hands
- [x] `hammer.png` 양손 그립에 부착
- [x] 마우스 방향으로 망치 회전
- [x] 팔 2본 IK로 어깨 → 손 연결
- [x] 카메라가 플레이어를 따라감 (`C` 키로 free camera 토글)

> 참고: 상자는 항아리 대신 카드보드 박스 에셋 사용.

---

### 1단계 — 망치 물리 프로토타입 (다음 우선)

목표: **마우스로 망치를 휘두르고, 발판에 닿아 반동으로 몸이 움직인다.**

- [ ] Matter.js 도입
- [ ] 박스(플레이어 중심 바디) — 중력, 충돌, 낙하, 회전 제한
- [ ] 망치 물리 바디 — 장애물과 실제 충돌
- [ ] 망치 ↔ 발판 충돌 → 반작용으로 박스 이동
- [ ] 망치를 걸어 몸을 끌어올리기
- [ ] 테스트용 사각형 발판

```
  ○ ← 캐릭터(박스)
  │
  ● ← 망치
────────────
   발판
```

❌ 하지 말 것: 캐릭터가 마우스를 따라 날아다니기, WASD 걷기/점프

---

### 2단계 — 세로 월드 + 카메라 추적 (물리 연동)

- [x] 플레이어 위치에 카메라 추적 (데드존 + 보간) — 비주얼 기준으로 선구현
- [ ] 물리 낙하 시 카메라도 아래로 따라감
- [ ] 맵 하단 스폰 → 위로 등반 가능한 테스트 발판 배치

---

### 4단계 — 1스테이지 (지상 / 폐허)

- [ ] 배경은 이미 적용됨 (노을 구간)
- [ ] 장애물 PNG + 충돌 영역 분리
  - 쓰러진 나무, 바위, 폐허 아파트, 소파, 자전거, 절벽, 잔해 등
- [ ] 난간·창틀·비상계단에 망치 걸기 가능
- [ ] (가능하면) 충돌 영역 편집 모드
- [ ] 1단계 정상 깃발

---

### 5단계 — 2·3스테이지 확장

**2단계 — 하늘**

- [ ] 비행기, 열기구, 배, 철탑, 구름 장식 등
- [ ] 날개·난간·철탑에 망치 걸기
- [ ] 2단계 깃발

**3단계 — 우주**

- [ ] UFO, 우주선, 외계인, 소행성 등 (배경에 행성 넣지 않음)
- [ ] **중력은 유지** (무중력 미구현 — 플레이 감각 유지)
- [ ] 3단계 최종 깃발

---

### 6단계 — 깃발·진행 시스템

- [ ] 단계별 깃발 도착 판정
- [ ] 1·2단계: `STAGE 1 CLEAR` 등 간단 연출 후 **플레이 계속**
- [ ] 3단계 깃발 = 최종 목적지 → 엔딩 트리거

---

### 7단계 — 피날레 엔딩

- [ ] 조작 비활성화
- [ ] “정상 도착” 연출
- [ ] 소행성 충돌 + 화면 흔들림
- [ ] 톰 사망, 항아리 잔류
- [ ] 영혼(`tom-soul.png`) 상승 + 카메라 추적
- [ ] 우주가 빛으로 전환
- [ ] 예수 등장 → 페이드아웃 → `THE END`

---

### 8단계 — 폴리시

- [ ] 화면 흔들림, 파티클, 그림자
- [ ] 물리 밸런스 조정
- [ ] 사운드 (구조만 미리 준비 가능)
  - 돌/금속/나무 충돌음, 바람, 우주 BGM, 깃발, 소행성, 엔딩 음악

## 7. 플레이어·물리 요약 (이후 구현 참고)

### 구조

```
  머리/몸 🦎
   /    \
 팔      팔
   \    /
    🔨 망치
  🏺 항아리
```

### 조작

| 입력 | 동작 |
|------|------|
| 마우스 이동 | 망치 방향 변경 |
| 크게 이동 | 크게 휘두름 |
| 망치 + 장애물 | 충돌·반동 |
| 바닥 밀기 | 상승 |
| 높은 곳 걸기 | 끌어올리기 |

키보드로 걷기/점프는 **없음**.

### 항아리

- 플레이어 중심 물리 객체
- 중력·충돌·낙하·밀림
- 회전은 과도하지 않게 제한

### 망치

- 실제 충돌 바디
- 손 위치 = 회전축
- 팔 이미지는 망치 각도를 따라감

## 8. 스테이지별 분위기

| 단계 | 배경 | 분위기 | 예시 오브젝트 |
|------|------|--------|----------------|
| 1 | 주황 노을 | 폐허 도시 + 자연 | 나무, 바위, 아파트, 소파, 자전거 |
| 2 | 파란 하늘 | 점점 비현실적 | 비행기, 열기구, 배, 철탑 |
| 3 | 검은 우주 | 별·블랙홀(배경) | UFO, 우주선, 외계인, 소행성 |

배경은 끊기지 않는 **하나의 긴 이미지**로 자연스럽게 이어진다.

---

## 9. 개발 원칙

1. **망치 물리가 재미의 핵심** — 그래픽보다 먼저 완성한다.
2. 에셋이 없으면 도형 placeholder로 검증한다.
3. 한 번에 전 스테이지를 만들지 말고 단계적으로 확장한다.
4. 임의로 점프/비행 조작으로 바꾸지 않는다.
5. PNG와 충돌 영역은 분리한다.
6. 월드 좌표와 카메라 좌표를 명확히 구분해 관리한다.
